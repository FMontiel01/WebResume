# Web Resume – HTML & CSS (Azure Hosted)

**Name:** Fernando Montiel  
**Project Name:** Web Resume 

---

## Project Description

This project is a web-based version of my professional resume created using HTML and CSS.
The resume follows the official Lewis University resume format and is designed to be suitable
for review by Lewis University Career Development Services. The resume is hosted publicly
using Microsoft Azure and includes a printable PDF version linked from the web page.

---

## Technologies Used

- HTML5
- CSS3
- Git & GitHub
- Microsoft Azure Static Website Hosting

Only source files required to view and execute the application, along with README.md and

---

## How to Run the Application

### Local Execution

1. Download or clone the repository.
2. Open `index.html` in a modern web browser (Chrome, Edge, or Firefox).
3. No compilation is required.

### Live Deployment

The resume is publicly accessible via an HTTPS-based URL using Microsoft Azure hosting.

---

## PDF Resume

A printable PDF version of the resume is included as `resume.pdf`.
The PDF was generated directly from the HTML resume using browser print-to-PDF functionality
with headers and footers disabled to ensure a professional appearance.

The PDF is linked on the main resume web page.
